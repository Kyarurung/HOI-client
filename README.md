# HOI-client

`dev.hoi.client.HoiClient`는 Fabric 진입점을 유지합니다. 구현은 `research`(연구 화면·트리), `screen`(국가·산업·첩보·팝업 화면), `ui`(공통 버튼·HUD·아트), `map`(지도 장면), `input`(단축키·지도 클릭·이동), `audio`(음악·효과음), `mixin`으로 나눕니다. 공통 진행 버튼은 `ui.PanelButton`입니다. 단위 테스트와 렌더링 검사는 해당 기능 패키지에 두고, `ResearchScreenGameTest`가 렌더링 검사의 진입점을 유지합니다. 이 패키지 이동은 `hoi:` 통신 ID나 저장 데이터 형식을 바꾸지 않습니다.

Minecraft **26.2 · Fabric · Java 25**용 HOI 전용 클라이언트입니다. 자국 현황, 연구, 정보기관과 지휘관 상세를 표시하며 연구·첩보 조작은 인증된 서버 API로 요청합니다.

정치 화면의 용어는 `세력`, `경제-정치 연합`을 사용하며 `선거 실시` 라벨은 표시하지 않습니다. 경제 모델·세력·경제-정치 연합·정치 체제 칸은 이름이나 수치 없이 이미지만 표시합니다. 빈 지도자·국가 중점과 정치 분류 아이콘은 외부 팩의 `politics/empty/` 원본 이미지를 사용합니다. 팩에 보관된 31개 국가·세력의 전체 인물·중점·정신 이미지가 곧 서버의 현재 지도자 선정이나 모든 루트의 실행 구현을 의미하지는 않습니다.

지도자·국가 중점·국민정신의 상단 제목 라벨은 생략하고 하단 구역 제목은 유지합니다. 지도자 이름은 초상화 아래 중앙에 배치하며, 국가 중점 이미지와 제목은 별도의 칸을 사용하고 제목은 중앙 정렬합니다. 다음 선거는 서버 날짜를 `다음 선거 5월 2032`처럼 표시하고 날짜에 `<gold>` 색상을 적용합니다. 선거 영역 아래 여백과 실제 클릭 영역도 함께 맞춥니다.

정치 상단 이미지는 각 칸의 중앙에 비율을 유지해 배치합니다. 지도자 영역은 기존 너비보다 8 GUI 단위 넓히되 전체 패널 너비는 유지합니다. 세부 이념 항목이 전송되면 통치 형태 대신 그 이름을 표시하고 호버로 설명을 보여줍니다. 현재 서버는 세부 이념을 추적하지 않으므로 일반 통치 형태를 유지하며, 원본 시작 이념이나 스크린샷의 특정 이념을 현재 국가 상태로 대신 표시하지 않습니다.

국민정신 아이콘 줄은 휠과 가로 휠로 끝까지 스크롤하며, 개별 아이콘 호버로 서버가 보낸 효과와 설명을 표시합니다. 지도자 초상화와 이름은 클릭 동작이나 강조 없이 같은 설명 툴팁만 표시합니다. 긴 툴팁은 Shift+휠로 읽습니다. 지도자 설명이 없는 스냅샷에는 임의의 인물·특성을 채우지 않습니다. 현재 서버의 지도자 필드는 비어 있으며, 국민정신은 등록된 실제 보정과 제공된 설명만 전송합니다. 렌더링 검증의 인물과 효과는 테스트 데이터이며 실제 캠페인 상태가 아닙니다. 국민정신 왼쪽은 이념 이미지 칸이며 비어 있어도 국민정신 호버·스크롤 영역에 포함되지 않습니다.

## 설치

1. 플레이어의 Minecraft 26.2에 Fabric Loader 0.19.5 이상과 Fabric API 0.159.0+26.2를 설치합니다.
2. `hoi-client-0.1.0-SNAPSHOT.jar`를 플레이어의 `mods/` 폴더에 넣습니다.
3. HOI 서버에 접속하여 `/hoi select`로 국가를 선택합니다.
4. `/hoi ready`로 전원 준비를 마치면 게임이 일시정지 상태로 시작합니다. **Shift+F** 또는 `/hoi menu`로 국가 메뉴를 엽니다. 연구는 메뉴의 연구 아이콘, `/hoi research` 또는 `/hoi-research`로 엽니다. R 연구 단축키는 제거했으며 일반 F의 보조 손 교체는 유지합니다.

`/hoi menu`로 국가 메뉴를 엽니다. 서버가 제공하는 Polymer 리소스팩을 수락해야 UI 이미지·지도·사단 모델이 표시됩니다. 이미지와 모델은 HOI-resourcepack에서 제공하며 클라이언트 JAR에는 포함하지 않습니다. 공유 `hoi_protocol`은 JAR에 내장되고, 전략 계산·저장은 서버가 담당합니다.

## 빌드와 테스트

먼저 인접한 `HOI-resourcepack` 저장소에서 `python scripts/build_pack.py`를 실행합니다. 이미 변환한 PNG가 포함되어 있어 재빌드에는 Steam이나 Pillow가 필요하지 않습니다. 다른 위치의 팩은 Gradle에 `-PhoiResourcePack=<resources.zip의 절대 경로>`로 지정합니다. 이후 Java 25로 실행합니다.

```bash
./gradlew test runGameTest remapJar --console=plain --no-daemon
```

Windows PowerShell:

```powershell
.\gradlew.bat test runGameTest remapJar --console=plain --no-daemon
```

출력물은 **`build/libs/hoi-client-0.1.0-SNAPSHOT.jar` 하나**입니다. `test`는 프로토콜·레이아웃 JUnit, `runGameTest`는 실제 Minecraft에서 외부 팩 로딩, 10개 메뉴, 패널 비율, 6개 기준 연구 슬롯, 첩보 선택·응답 대기·권한 만료, 키보드 비행과 창 크기 변경을 검사합니다. 개발 실행은 `./gradlew :client:runClient`입니다. Linux에서는 `xvfb-run -a ./gradlew test runGameTest remapJar`를 사용합니다. CI는 `HOI-resourcepack`에 등록한 읽기 전용 배포 키의 개인 키를 `HOI_RESOURCEPACK_SSH_KEY` Actions 저장소 시크릿으로 사용합니다. 해당 키는 이 비공개 리소스팩 저장소에만 접근하며, 체크아웃 후 자격 증명을 유지하지 않습니다. 팩 버전은 워크플로의 커밋 SHA로 고정합니다. 팩을 갱신할 때 해당 SHA도 함께 갱신하고 렌더링을 검증합니다. 이 시크릿을 사용할 수 없는 외부 PR에서는 전체 렌더링 검증을 실행할 수 없습니다.

테스트 이미지는 `client/build/run/clientGameTest/screenshots/`에 생성됩니다. UI 테스트는 시험용 데이터로 렌더링을 확인하며, 실제 다중 접속 서버에서 연구 완료까지의 전체 연동 검사는 별도입니다.

## 화면과 게임 규칙

메뉴는 HOI식 금속 프레임, 어두운 내용 영역, 입체 제목 띠와 회색 선택 표시를 사용합니다. 상단은 원작 버튼 이미지의 테두리를 그대로 살린 왼쪽 도구 모음이며, 화면 전체에 넓은 버튼을 늘어놓지 않습니다. 국가 정보의 하위 탭과 경제·무역 전환도 아이콘만 표시하고 툴팁·접근성 이름을 유지합니다. 새로고침 버튼과 서버 현황 표시는 없으며 서버 현황 자동 조회는 유지합니다. 하단에 기관 관리처럼 실제 동작이 없는 메뉴는 내용 영역을 끝까지 사용합니다. 이미지 팩은 기존 HOI-resourcepack을 사용하며 추가 이미지를 JAR에 넣지 않습니다. GameTest는 일반·소형 창의 메뉴, 상세 창, 하위 탭 및 버튼 겹침을 실제 렌더러에서 검사합니다. 테스트에 보이는 국가 수치는 화면 검증용 데이터이며 운영 서버의 현황이나 다중 접속 동기화 검증을 뜻하지 않습니다.

상단 메뉴 순서는 국가 정보, 결정, 정보기관, 연구, 무역 & 경제, 건설, 생산, 모병 및 배치, 군수, 장교단입니다. 공용 메뉴는 연구 슬롯·트리·기술 상세에서도 유지합니다. 국가 정보 버튼은 왼쪽에서 두 줄 높이를 차지하고 오른쪽은 높이 약 40%의 지표 줄과 약 60%의 메뉴 아이콘 줄로 구성합니다. 스크린샷처럼 작은 자원 표시 줄 아래에 메뉴 아이콘을 배치하며, 국가명·국가 코드·시간·배속과 업적은 상단에 넣지 않습니다. 지표는 정치력·안정도·전쟁 지지도·인력·공장·연료·병참 상황·수송·지휘력·육군 경험치·공군 경험치·해군 경험치·집권 정당 지지도 순서입니다. 핵폭탄·실질 GDP·국가부채도 표시합니다. 세계 긴장도는 국가 정보 버튼과 같은 크기로 오른쪽 끝에 고정하고 TFR 원본 DEFCON 이미지 아래에 %를 표시합니다. `world_tension_icon_big_strip.dds`의 10개 프레임을 10% 단위로 전환하며 0~9%는 첫 프레임, 90~100%는 마지막 프레임입니다. 숫자와 DEFCON 글자, 색상, 투명도를 그대로 보존하며 같은 숫자가 두 구간에 반복되는 원본 배열을 유지합니다. 서버 값이 없으면 특정 DEFCON 단계를 추정하지 않습니다. 핵폭탄은 연구 여부와 관계없이 게임 시작부터 나타납니다. 공장 아래는 에너지, 병참 상황 아래는 보급 효율, 수송 아래는 수송 효율 막대이며 0..1의 서버 값이 있을 때만 초록색으로 채웁니다. 작은 창에서 모든 지표가 들어가지 않으면 상단 줄에 마우스를 올리고 휠로 나머지 지표를 볼 수 있습니다. 모든 화면 크기에서 공용 메뉴 탭의 라벨을 숨기고 작은 원본 버튼 안에 아이콘을 중앙에 표시하며 메뉴 이름은 툴팁과 접근성 이름으로 제공합니다. 연구에서 다른 메뉴로 전환하면 연구 세션을 닫고 서버에서 해당 국가 현황을 새로 조회합니다. 패널 폭은 첨부된 2560px 화면과 TFR 원본 `interface/country*view.gui`의 컨테이너 폭을 기준으로 합니다. 국가 정보 726px(약 **28.4%**), 무역·경제 620px(약 **24.2%**), 군수 560px(약 **21.9%**), 연구·정보기관·모병·건설·생산·결정·장교단은 550px(약 **21.5%**) 비율로 표시합니다. 작은 창이나 큰 Minecraft GUI 배율에서는 글자와 버튼을 위해 국가 248, 무역 244, 기본 184 GUI 단위의 최소 폭을 보장합니다. GUI 3 기준에서도 고정 35%로 늘리지 않고 이 원본 비율을 우선합니다. 읽을 공간이 부족할 때 최소 폭까지 확장하며, 일반 화면에서는 정치 40%·기타 35% 안에 둡니다. 최소 폭도 들어가지 않는 작은 창은 화면 안에서 읽을 수 있는 폭을 우선합니다. 원본 파일은 개발 때 치수만 참조하며 실행 시 Steam 설치를 요구하지 않습니다. 상세 창과 전체 연구 트리는 별도로 열립니다. 사이드바에서 설정된 이동·점프·내려가기·달리기 키를 사용할 수 있고, 상세 창·검색·전체 트리·포커스 이탈 시 이동 입력을 해제합니다.

연구 슬롯 배치는 최대 6개까지 수용하며 실제로는 서버가 제공한 슬롯만 표시합니다. 현재 국가의 최대 슬롯 수는 5개이고 클라이언트에서 빈 슬롯을 추가하지 않습니다. 페이지 번호와 좌우 이동 버튼은 표시하지 않습니다. 슬롯 원본 이미지는 배경으로 유지하고 진행 중인 기술 이미지를 슬롯 중앙에 겹쳐 표시합니다. 슬롯에는 순번을 붙이지 않고 연구 선택 라벨을 배경 안쪽으로 내려 배치하며 저장 일수 문구는 슬롯에서 숨기되 서버의 저장 일수와 남은 연구 기간 계산은 유지합니다. 남는 세로 공간은 상단 연구 배너에 배분합니다. 내부 8개 연구 분야를 유지하며 화면에는 보병, 지상 & 항공 지원, 기갑, 포, 해군, 해군 지원 장비, 공군, 공학, 산업의 9개 아이콘 탭을 표시합니다. 탭에는 라벨을 붙이지 않고 툴팁과 접근성 이름만 제공합니다. `category/`와 `tabs/`는 같은 원작 UI 아이콘을 사용하며, 선택한 탭의 아래 테두리는 연구 패널에 이어집니다. 기술 상세에도 해당 아이콘 탭을 부착합니다. 모든 이미지는 원본 비율을 유지합니다. 상단 연구 배너만 영역을 채우도록 중앙 부분을 잘라 표시하고 나머지는 지정 영역 안에 중앙 정렬하며, 탭·사진의 최대 크기는 패널 너비와 독립적으로 제한합니다.

휠로 세로 이동, 가로 휠·우클릭 드래그로 트리를 이동합니다. 기술 상세에서 이미지·연구일·효과·해금 장비를 확인하고 실제 시작·중단을 요청합니다. TFR 전체 DLC 연구 415개를 원본 좌표와 선행 연결로 표시합니다. 보병·지원·해군·해군 지원은 가로형, 기갑·포병·공군·공학·산업은 세로형입니다. 원본 기술은 작은 카드로 표시하고 사진·이름을 유지하며 전체 이름은 툴팁에서도 확인합니다. 겹치는 원본 카드는 필요한 부분만 이동합니다. 기존 예제 기술은 진행·완료 이력이 있을 때 함께 표시합니다.

정보기관은 서버가 제공한 고용·해고, 임무 및 대상 선택, 13개 업그레이드, 해독 시작·정지·공개, 3개 작전 준비·취소를 지원합니다. 비용·조건·소유권·진행·저장은 서버에서 처리하고 클라이언트는 일회용 세션 리비전으로 요청합니다. 국가 중점 목록은 현재 이벤트 플래그·분기·선행 조건을 재조회합니다. 지휘관 상세는 실제 서버 능력치와 배속 군을 표시합니다.

게임 시작일은 **2020-01-01**이며 X1은 **10틱/시간**, 속도는 일시정지·X1~X5입니다. 보병 연도 축은 **2000년부터**, 기갑은 **1980·2018·2020·2022·2024·2028·2032년**입니다. 원본 415개 외에 기존 예제 기술 8개의 저장은 유지합니다. 국가 효과 29종(215항목)과 9개 기술의 시설 해금은 실제 서버 계산에 연결됩니다. 원본 장비·모듈·부대 해금, 장비별 능력치, 일부 경제 및 국가별 완료 스크립트는 상세창의 적용 대기 항목이며 실행하지 않습니다. 정치 및 거시경제 수치는 읽기 전용 현황이며 전체 법률 교체 UI, 원작 후보 요원·무작위 작전 단계, 육해공군 잠입·거짓 정보 작전, 지휘관 특성 트리·임명, 3D 미리보기는 아직 이식되지 않았습니다. 첩보는 HOI 코어에 구현된 세 작전과 실제 기간·조건을 사용합니다. 실제 다중 접속 인증·진행·팩 다운로드 검증은 별도입니다.

연구 개요에는 슬롯 개수 라벨을 표시하지 않습니다. 건설 속도와 사용 가능한 에너지는 원본 아이콘 옆에 숫자만 표시하고, 건설 속도의 정수 증감률과 에너지 값이 0 이상이면 초록색(`#55FF55`), 음수이면 dark_red(`#AA0000`)를 사용합니다. 항목명과 서버에서 받은 계산 내역은 호버 툴팁에서 확인합니다. 계산 내역이 없는 구버전 스냅샷에는 제공되지 않았다고 표시하며 클라이언트에서 계산을 추정하지 않습니다.

건설 상단 민간공장과 수리 아이콘은 HOI4 바닐라 `non_available_factory_icon.dds`, `factory_wrench_icon.dds`를 외부 팩에서 읽습니다. 민간공장 배정량/총량은 모두 배정했으면 초록색(`#55FF55`), 남은 공장이 있으면 gold(`#FFAA00`)입니다. `미사용 n` 요약 라벨은 숨기되 공장 배정 내역 툴팁과 서버 수치는 유지합니다.

연구 상세를 제외한 패널은 요청 성공·실패·시간 초과 메시지를 내부나 하단에 표시하지 않습니다. 서버 검증, 응답 대기 중 중복 요청 방지와 자동 재조회는 유지합니다.

건설 상단 에너지 숫자는 서버 공급량에서 수요를 뺀 잔여량입니다. 음수이면 TFR `missing_resources_strip.dds`의 에너지 프레임, 0 이상이면 `resources_strip.dds`의 에너지 프레임을 표시합니다. 상단 요약의 테두리는 지표 아이콘 아래 4 GUI 단위의 내부 여백과 소비재 행 앞 3 GUI 단위의 간격을 둡니다. GUI 너비가 800 이상이면 패널 너비에 원본 비율을 직접 적용하고, 더 좁은 창에서는 기존 가독성 최소 너비를 유지합니다.

## 서버 명령과 시간 표시

클라이언트는 /hoi 루트를 등록하지 않습니다. 이전 버전의 client-sided command 오류는 클라이언트 루트가 서버의 start·map·ready·stop을 가로챈 것이 원인입니다. 최신 클라이언트 JAR로 교체하고 클라이언트를 재실행하세요. /hoi research는 서버가 화면 열기를 요청하고 클라이언트가 기존 인증·요청 제한을 적용하는 OPEN 요청을 보냅니다. /hoi-research는 독립적인 명령이며 Shift+F는 국가 메뉴를 엽니다.

날짜·시간은 2020년 1월 1일 01시, 배속은 1배속~5배속으로 표시합니다. 배속 색상은 초록·노랑·주황·빨강·진한 빨강이며 | 구분선은 진한 회색입니다. 배속과 일시정지는 관리자만 변경합니다. 관리자 /hoi stop은 국가 선택과 캠페인을 초기화하고 2020년 1월 1일 00시·일시정지로 되돌립니다. 초기화 백업은 서버에서 보관하며 Minecraft 서버 자체는 종료하지 않습니다.

클라이언트 GameTest는 실제 등록 함수를 호출하여 /hoi를 등록하지 않고 /hoi-research만 등록하는지 확인하며, 연구 헤더의 한국어 날짜·배속을 실제 렌더러로 검사합니다. 운영 서버와 플레이어 클라이언트의 재접속 검증은 별도입니다.

상단 수치는 메뉴·연구의 기존 비공개 JSON 스냅샷에 선택적 `hud`·`national` 필드로 전달합니다. 구버전 서버의 누락 필드는 알 수 없음(`—`)으로 처리하고 기존 wire ID를 유지합니다. 정치력·유효 안정도·전쟁 지지도·인력(예비 인력)·공장(민간/군수/조선소 합계)·연료·수송선·지휘력·군종 경험치·집권 정당 지지도·세계 긴장도는 실제 서버 값입니다. 실질 GDP·부채는 저장된 국가 회계 값(십억 달러)을 읽으며 실행 중인 TFR 이야기 변수 `gdp_total_var`·`debt_var`가 있으면 이를 우선합니다. 사용자가 지정한 한국의 새 캠페인 시작값은 실질 GDP **1.707조(1707십억)**, 부채 **704.314십억**입니다. 클라이언트는 GDP를 조, 작은 경제 수치를 B(십억 달러)로 소수점 셋째 자리까지 표시하며 툴팁에 전체 원값을 표시합니다. 이후 변경값은 저장·불러오기와 국가 갱신에서 보존합니다. 기존 국가 저장에 회계 필드가 없으면 `—`로 유지하고 시작값으로 덮어쓰지 않습니다. 현재 기본 캠페인에는 국가 단위 병참량·보급/수송 효율과 전체 TFR 경제·핵무기 체계가 연결되지 않아 해당 미등록 값은 `—`, 효율 막대는 빈 상태입니다. 핵폭탄 항목은 시작부터 표시하며, 실제 등록된 핵무기 기술 `nukes`에 연결된 장비 재고를 연구 완료 여부와 관계없이 집계합니다. 재고 종류가 등록되었으면 0개도 표시하고 종류 자체가 없으면 `—`입니다. UI를 열어 수치·기술·무기를 생성하지 않습니다. UI GameTest의 채워진 막대와 수치는 화면 검증용이며 실제 다중 접속의 동기화를 증명하지 않습니다. 새 HUD 아이콘 팩과 HOI 서버 개발 빌드가 함께 필요하며 운영 서버는 자동으로 시작하거나 재시작하지 않습니다.


정치력은 소수부를 버리고 1000부터 `1.0K`, `1350 → 1.3K`, `2000 → 2.0K`처럼 최대 네 글자로 표시합니다. 서버의 정치력 상한 2000을 유지하며 지휘력은 소수부 없이 세 자리 정수까지 잘리지 않게 표시합니다. 툴팁의 원값과 누락 값 `—` 처리는 유지합니다. 건설 대기열 툴팁은 내부 건물 ID 대신 서버가 제공한 이름(민간공장·군수공장 등)을 표시합니다. 숫자 경계값은 JUnit으로, HUD 글자 폭과 번역된 건설 화면은 실제 클라이언트 렌더링으로 확인하며 운영 서버 접속 검증은 별도입니다.

건설 선택 목록은 주 건물(기반시설·공군기지·대공포·레이더), 공유 건물(공장·조선소·정유시설 등), 지역 건물(보급허브·해군기지·요새 등) 순서로 배치합니다. 별도 분류 제목이나 탭 없이 두 줄의 구분선만 사용하며, 작은 창에서는 전체 목록을 스크롤합니다. 댐·산악 댐은 선택 목록에서 제외하며 기존 지도 시설이나 서버 저장값은 변경하지 않습니다.

2026-09-09 건설 변경 검증: JUnit과 실제 UI 렌더링에서 구분선 간격·댐 제외·소형 창 스크롤·좌클릭 건설/우클릭 취소 요청을 확인했습니다. 오키나와 해협 경로 검사를 포함한 전체 GameTest도 통과했으며, 운영 서버에서의 실제 접속 검증은 별도입니다.

## TFR 연구·혜택 검증 (2026-09-08)

연구 카테고리는 원본 이미지의 투명한 좌우 여백을 제외해 거의 붙여 표시합니다. 연구 카드는 기술명 띠 없이 비율을 유지한 이미지만 표시하고 이름은 툴팁과 상세창에 남깁니다. 장비 구분 제목은 반드시 해당 연구 대상 위에 배치하며, 실제 글꼴 크기로 카드·다른 제목과의 겹침을 피합니다. 연도 표시에도 여유를 확보하고 모든 연구 트리의 위아래에 빈 한 줄을 둡니다. 상세창 위의 카테고리 돌출 탭은 제거했습니다. 일반·소형 창의 전체 카테고리를 실제 렌더러로 검사하며 서버의 연구 판정과 진행량은 바꾸지 않습니다.

배너 아래에 제한된 혜택의 남은 횟수와 국가 연구 속도를 표시합니다. 혜택 버튼은 종류·대상·속도·선행 연도 감소를 안내합니다. 선택한 슬롯이 사용 중이면 남은 빈 슬롯을 자동 선택하고 서버도 이를 검증합니다. 선행 AND/OR, 배타 분기, 국가별 중점·플래그 조건과 예상 일수를 서버가 결정합니다. 슬롯을 중단·재개해도 혜택을 다시 소비하지 않습니다.

연구 payload는 v2이며 서버와 클라이언트의 공유 protocol 소스를 함께 갱신해야 합니다. v1 연구 패킷과 호환되지 않습니다. 상한은 512개 기술, 16개 슬롯, JSON 400,000문자입니다. 국가 메뉴·첩보 payload ID는 유지됩니다. 공통 연구 사진 413개와 대한민국 전용 항공기 사진 2개는 HOI-resourcepack에서 읽습니다. 12인치 부포는 연구 목록에서 제거했습니다. 두 항공기의 공통 원본이 없는 다른 국가는 기존 분야 아이콘을 유지합니다.

`test runGameTest remapJar`는 415개 시험 스냅샷으로 모든 탭의 배치·클릭, 가로·세로 방향, 슬롯 자동 선택, 혜택·상세창과 작은 창을 확인합니다. 실제 Minecraft 렌더러의 `hoi-tfr-*` 스크린샷을 `client/build/run/clientGameTest/screenshots/`에 기록합니다. 시험 값 +4%·혜택 2회는 국가에 지급하지 않습니다. 전체 fixture는 배포 JAR에 포함하지 않습니다. 실제 운영 서버 연결에서 연구 시작~완료, 지연·재접속, 리소스팩 다운로드 검증은 남아 있습니다. 운영 서버를 자동 변경하거나 시작하지 않습니다.

기갑 33개와 산업 60개는 2026-09-08 추가 스크린샷에 맞춘 전용 배치입니다. 기갑은 엔진·정찰전차·주력전차·수륙양용·장갑·보조 무기/탄약의 열을 분리하고, 차체만 넓은 카드로 표시합니다. 산업은 작은 정사각형 아이콘으로 생산·산업·건설/채굴·합성 석유를 구분합니다. 같은 행의 연구는 좌우로 연결하며 다른 행은 공통 분기선으로 연결합니다. 기존 원본 좌표에 겹침이 있어도 해당 열을 유지합니다. 양쪽 연도 축은 화면 참조이고 실제 기술 연도·효과·선행 조건은 서버 정보를 그대로 사용합니다. 큰 화면에서는 비율에 맞춰 확대하고 작은 화면은 스크롤로 접근합니다. 415개 기술 전체에 9개 탭별 고정 배치를 적용합니다. 연구 탭은 좌측에 나란히 놓고 본문 상단에 붙이며 원본 선택·비선택 프레임을 전환합니다. 기술 갈래는 원본 XOR 이미지로, 특별 묶음은 테두리로 표시합니다. 기술 검색과 처음 위치/슬롯 목록 버튼은 없으며 Esc로 돌아갑니다. `hoi-armor-rearranged`, `hoi-industry-rearranged`와 소형 창 스크린샷으로 검증합니다.


## 건설 예약과 공장 배정

건설 메뉴는 원본 비율의 왼쪽 패널과 원본 건물 아이콘을 사용합니다. 건물을 선택한 뒤 1인칭 시점에서 지도 위의 자국 주를 좌클릭하면 서버가 소유권·현재 통제·연구·슬롯을 검사하고 건설을 예약합니다. 우클릭은 해당 주에서 선택한 건물의 마지막 건설 예약 하나를 취소합니다. UI를 닫고 건설 지도 도구를 든 상태에서도 같은 조작을 사용합니다. 완성된 건물은 철거하지 않습니다. 목록의 우선순위 변경·취소와 수리 우선 공장 −/+는 서버에 요청하고 저장합니다. 수리 우선 공장은 제목과 분리된 숫자 칸을 사용합니다. 작은 창의 건설 목록과 건물 아이콘 목록은 각각 스크롤합니다.

소비재·무역/기관 예약을 먼저 제외하고, 손상 건물이 있을 때 수리 우선 공장을 확보한 뒤 각 건설에 최대 15개를 배정합니다. 남는 공장 중 최대 15개는 수리에 사용하며 나머지는 미사용으로 표시합니다. 같은 날 건설을 마친 공장을 수리에 중복 배정하지 않습니다. 소비재, 사용/총 공장, 미사용 공장, 건설 속도, 에너지 공급/수요 및 실제 수리 배정은 같은 서버 계산을 사용합니다. 에너지 충족률은 상단 공장 아래 막대에도 반영합니다. 수리 설정은 기존 국가 저장에 선택적으로 추가되어 이전 저장은 0개 우선 지정으로 시작하며 진행을 초기화하지 않습니다.

현재 건설 가능한 종류는 등록된 민간공장·군수공장·조선소·기반시설·공군기지·대공포·레이더·정제시설·연료 저장고 9종입니다. 조선소는 항구가 있는 주에만 예약합니다. 나머지 원본 아이콘은 조건 안내와 함께 비활성화하며, 미등록 발전소·댐·원자로·지역 시설을 임의 생성하지 않습니다. 에너지는 현재 등록된 석탄 자원과 무역 결과를 이용합니다. 공급은 `10 + 9 × 석탄`, 수요는 `공장 수 × min(6.6, 0.25 + 0.0125 × 공장 수)`인 현재 HOI 규칙입니다. 에너지 충족률에 따라 건설 공장당 작업량은 4~5, 군수공장 생산은 3.5~4.5, 조선소 생산은 2~2.5로 변합니다. 발전소 생산·특수 프로젝트 수요·TFR의 모든 에너지 보정과 전력 거래는 아직 구현하지 않았으며 원작 전체 전력망과 동일한 계산으로 간주하지 않습니다.

건설 요청/응답은 공유 `hoi:construction_request_v2`·`hoi:construction_response_v2`을 사용합니다. 서버가 발급한 세션과 단일 사용 리비전으로 중복 예약을 차단하고, 국가 권한 상실 시 화면을 닫습니다. 지도 요청에는 국가나 주 ID 대신 제한된 시선 방향을 보내고 서버가 플레이어 위치에서 주를 찾습니다. 기존 연구 payload는 변경하지 않습니다.

검증에는 공장 배정·에너지 부족·저장 복구 JUnit, 실제 지도 좌표와 일반 지도 클릭의 서버 GameTest, 작은 창의 수리 버튼·목록 스크롤·권한 만료를 포함한 실제 클라이언트 렌더링이 포함됩니다. UI fixture와 mock 서버 플레이어 검증이며 실제 다중 접속의 클라이언트→서버 왕복·재접속·팩 다운로드 검증은 별도입니다. 운영 서버는 시작하거나 재시작하지 않습니다.

Politics uses seven icon rows (government, economic laws, military laws, social laws, development, military staff, research & production) and widens to a readable minimum of 248 GUI pixels. Foreign-country inspection has diplomacy and civilian/army/navy/air ledger tabs; unknown fields stay unknown. The server filters every field at its own intelligence threshold before sending it. ## TFR 강·지형 모델 렌더링 검사

`AtlasSurfaceRenderChecks`는 서버가 내보낸 한국 주변 실제 국가색·전체 블록 운반 상태와 정적 도형을 일회용 월드에서 확인합니다. 새 `hoi:atlas_scene_v3`은 경계·강·묘목·진흙·모래·도시를 디스플레이 엔티티 없이 32블록 타일·재질별로 렌더링합니다. 도형 페이지가 모두 조립되면 서버에 확인을 보내 기존 표시를 해제합니다. 불완전·혼합 장면은 게시하지 않으며 새 페이지 수신 전에는 서버의 호환 표시가 유지됩니다. 도시 모델은 외부 팩을 사용하고, 육군 강은 vanilla 애니메이션 물 텍스처, 해군·공군 강은 각 바다의 기본 콘크리트 재질을 사용하며 검정 장식 테두리는 표시하지 않습니다. 좁은 물을 경로 중앙에 맞춰 기존 경계선 위에 불투명하게 표시하므로 물 밖으로 검정 선이 비치지 않습니다. 국가·주·프로빈스 경계 도형은 삭제하지 않습니다. 언덕 1칸·산악 2칸 실제 지형과 소형 지형은 모든 지도에 표시하고, 강 구간은 육군·해군·공군에 표시합니다. 주·프로빈스·강은 높은 쪽 지형과 ㄱ자 높이 연결을 따릅니다. 해군은 육지 주·해역·해상 프로빈스, 공군은 제공권·육지/바다 이음선을 표시합니다. 새 서버의 해안 ID 보정과 동일한 좌표로 사진의 빈 사각형 위치를 검사합니다. 경계는 서버가 실제 셀 마스크로 잘라 보낸 면을 사용하며 화면 밖 교차 구간도 시험 장면 범위로 자릅니다. 실제 렌더러는 물 높이·도시 확대·수도 이름·승점도 촬영하지만 운영 서버의 payload 왕복·재접속·다중 접속·FPS/MSPT 검증은 별도입니다. 새 서버와 클라이언트 JAR를 함께 사용해야 하며 정적 에셋과 이 fixture는 배포 JAR에 포함하지 않습니다.

표시 숫자는 최대 소수점 두 자리에서 반올림하며 저장·계산 정밀도는 서버에서 유지합니다. 수도 이름 크기는 서버의 디스플레이 설정을 따릅니다.

지도 도형은 16블록 타일로 나누고 카메라의 높이 차이를 포함한 거리로 숨깁니다. 경계와 강·묘목·진흙·모래·도시 모델은 모두 64블록 범위이며 가까워지면 다시 표시합니다. 시야 밖 타일도 제출하지 않습니다. 실제 지형 블록의 청크 렌더링 거리는 이 설정과 별개입니다. 실제 렌더러 GameTest는 가까움→64블록 안→64블록 밖→복귀에서 8종 재질 타일이 8→8→0→8개로 바뀌는 것을 검사합니다. 16블록 공간 인덱스에서 가까운 후보만 검사하며, 타일 하나가 64개보다 많은 버킷을 차지하면 별도 거리 검사로 메모리 증가를 제한합니다. 멀리 배치한 256개 도형의 검색 제외와 1,024블록 긴 도형의 표시도 검사합니다. 이는 표시 제한 검증이며 실제 사용자 클라이언트의 FPS 상승 수치는 측정하지 않았습니다.

## 생산·무역·군수·모병 연결

생산, 무역 & 경제, 군수, 모병 및 배치 메뉴가 공유 `hoi:industry_request_v1`·`hoi:industry_response_v1`로 연결됩니다. UUID 국가 권한, 서버가 발급한 선택지와 단일 사용 리비전을 검증하며 정상 변경은 서버 저장을 요청합니다. 구버전 서버에는 이 조작 프로토콜이 없어 기존 조회만 사용할 수 있습니다.

- 생산: 보병 및 포병 장비 제작·기갑 차량 제작·항공기 제작·함선 건조 버튼으로 등록·해금된 장비를 선택합니다. 라인 교체·삭제·우선순위와 공장 −/+를 조작합니다. 군수공장의 라인당 150개 제한을 없앴으며 실제 국가 보유 공장 수가 상한입니다. 함종별 조선소 5/10/15개 제한은 유지합니다. 일일 생산량과 7종 자원 수요·생산 효율은 실제 서버 계산을 표시합니다. 안정도 생산 효과·전력 충족률 항목은 화면과 툴팁에서 생략합니다. 설계사/MIO는 포함하지 않습니다.
- 무역: 자원별 추출·수입·수출 배정·생산 수요·잔여량을 보고 가용 민간공장으로 수입 계약을 체결하거나 취소합니다. 소유한 섬 하나 때문에 육상 경로가 없다고 판정하지 않으며 모든 자국 통제 지역에서 연결을 확인합니다. 경제 화면은 저장된 실질 GDP·부채, 공장 배정, 전력·연료·인력 현황을 표시합니다.
- 군수: 연구로 해금됐거나 창고 비축량이 있는 장비만 표시합니다. 서버가 지정한 같은 장비 계열은 수량과 일일 생산량을 합산하고 최신 연구 완료 모델의 이름과 이미지를 사용합니다. 구형 장비 재고를 신형으로 변환하지 않으며 마우스를 올리면 모델별 창고·훈련 지급·배치 사단 휴대·부족 수량을 볼 수 있습니다. 미연구 장비도 비축량이 있으면 포함하지만 최신 연구 이미지 선택에서는 제외합니다. 지도 자원은 매일 공급 가능한 생산 자원량이며 광석을 별도 창고에 쌓는 방식은 아닙니다. 자원 부족은 기존 서버 생산 페널티를 적용합니다.
- 모병: 자국 배치 장소와 편제를 선택해 훈련을 예약하고 우선순위를 변경하거나 취소·조기 배치합니다. 실제 인력과 창고 장비가 지급되고, 보급 경로·자국 통제·장비 충족 조건 아래 시간이 진행됩니다. 훈련 100%에 자동 배치하며 조기 배치는 20% 이상에서 서버가 검사합니다. 취소 시 지급 인력·장비를 반환합니다.

## TFRKP 알림과 HUD 상세

국가·글로벌·슈퍼 이벤트 창은 이전보다 약 15% 작게 표시하며 작은 창에서는 읽기 가능한 최소 크기를 유지합니다. 국가·글로벌 이벤트의 제목·본문·선택지 글씨는 기본 크기의 90%이며 슈퍼 이벤트 글씨는 기존 크기입니다. Minecraft 기본 폰트를 사용하고 별도 폰트 팩이 있으면 그 설정을 따릅니다. 긴 본문은 스크롤하고 많은 선택지는 기존 선택지 이동 버튼으로 확인합니다.

연구 툴팁은 연구명, 미충족 선행 기술, 연구 시간, 소수점 두 자리의 선행 연도 경고, 빈 줄, 효과·사용 가능 장비 순서입니다. 충족한 선행 조건과 과거 기술의 선행 경고는 숨깁니다. 효과는 버프를 `+`·초록(`green`), 디버프를 `-`·진한 빨강(`dark_red`)으로 표시합니다. 비용·소비 감소도 버프이므로 화면에서는 `+`를 사용하며 실제 계산·저장값은 바꾸지 않습니다. 부호 없는 수치·장비명·시설 키워드는 금색(`gold`), 항목명·인력·조직력·훈련 시간·병종명은 흰색입니다. 서버의 비율 0.07은 +7%로 표시하고 +7.0%의 불필요한 소수점은 없애되 2.5%와 장비의 절대 능력치 0.5는 보존합니다. 원본 참고 효과의 적용 대기 구분도 유지합니다.

국가 전용 번역이 있으면 연구명·완료 제목·해금 장비/부품명에 우선합니다. 대한민국의 K1 기관단총·K2 돌격소총은 TFRKP 한국어 원문을 사용하고 괄호 안 모델 병기는 표시하지 않습니다. 선택적 `ResearchView.Source.localizedNames`가 없는 구버전 JSON은 공통 이름으로 표시합니다. 완료 이동용 `hoi:completion_details_v1`은 기존 payload를 변경하지 않고 추가했으며 닫힌 팝업 토큰의 이동 응답은 무시합니다. 이 동작에는 함께 빌드한 HOI 서버 모드와 클라이언트가 필요합니다.

`Shift+F`는 국가 메뉴를 엽니다. 기존 R 연구 단축키는 제거했으며 연구는 메뉴의 연구 아이콘이나 `/hoi-research`로 엽니다. 기본 F의 보조 손 교환은 유지합니다. Enter와 숫자패드 Enter는 완료 팝업을 확인하고, 선택지가 하나인 이벤트는 해당 서버 선택지를 실행합니다. 여러 선택지가 있는 이벤트는 키보드로 선택한 버튼을 실행하며, 선택한 버튼이 없으면 효과를 고르지 않고 창만 닫습니다. 완료 알림은 서버가 접속·국가 변경 시 기준 상태를 잡은 뒤 새로 완료된 항목만 순서대로 전달하므로 과거 완료 전체를 재접속 때 재생하지 않습니다. 클라이언트 확인 버튼은 연구 보상·중점 효과를 다시 지급하지 않습니다.

상단 HUD 툴팁에는 서버가 제공하는 현재 값·일일 변화·보정 출처·사용량을 여러 줄로 표시합니다. 긴 설명은 `Shift+휠`로 스크롤합니다. 선택적 JSON `CountryHud.details`가 없는 구버전 서버는 기존 값과 `세부 내역 없음`을 표시하고, 보고되지 않은 수치는 `—`로 남깁니다. GDP·부채·연료·정치력 등의 설명은 저장된 값과 실제 서버 계산을 사용합니다. 안정도 생산 효과와 전력 충족률 별도 설명은 생략합니다. 전체 TFR 거시경제·정치 시뮬레이션을 이 UI가 새로 구현하는 것은 아닙니다. `DialogView.presentation`도 선택적 필드로 이전 JSON과 호환됩니다.

검증은 실제 연구·중점 완료 감지와 중복/재접속 기준, HUD 조회의 상태 불변 및 일일 연료 계산 일치, 프로토콜 호환성을 검사합니다. 클라이언트 GameTest는 원본 팩을 읽어 일반·소형 창의 5종 팝업, 긴 설명 스크롤, Enter 선택 요청, 닫힌 창의 지연 응답, 실제 키 입력 경로에서 Shift+F와 기본 F의 분리를 확인합니다. 통합 시험 서버는 국가 메뉴 프로토콜을 제공하지 않으므로 이 입력 검사는 실제 운영 서버에서 메뉴가 열리는 왕복 검증을 대신하지 않습니다. 실제 다중 접속·재접속·팩 다운로드 확인은 별도이며 운영 서버를 자동 시작하거나 재시작하지 않습니다.

## 누락 연구 이미지 수정 (2026-09-09)

신궁과 발전된/미래형 다목적 기체는 확인된 원본 그림을 연구 카드·슬롯·상세창에서 사용합니다. KOR 전용 그림은 인증된 스냅샷의 국가가 대한민국일 때만 선택하고, 다른 국가의 공통 이미지 선택은 유지합니다. 장비 상세 그림이 없으면 같은 연구의 국가별 그림을 대표 이미지로 표시합니다. 12인치 부포는 서버 연구 목록에서 제거했으며 시험용 목록도 415개로 맞췄습니다.

실제 클라이언트 GameTest의 `hoi-research-three-original-images` 화면으로 세 원본을 촬영하고 국가별 자원 선택과 상세 카드 연결을 확인합니다. 운영 서버/클라이언트 설치와 다중 접속 확인은 별도입니다.

표시 명칭은 원본 번역 파일에 따라 대한민국의 `antiair2`는 `KP-SAM 신궁`, `advanced_small_airframe`은 `발전된 미래형 다목적 기체`, `modern_small_airframe`은 `미래형 다목적 기체`입니다. `HOI/scripts/import_research_names.py`로 명시된 원본 항목을 다시 가져오며 저장 ID·비용·진행은 변경하지 않습니다.

추가로 `advanced_medium_airframe`과 `advanced_large_airframe`은 각각 `발전된 미래형 무인기체`, `발전된 미래형 대형 기체`입니다. 기체 설계용 번역 별칭에 의해 덮어써지지 않도록 연구 원본 이름을 명시적으로 가져옵니다.

외부 팩은 `resources.zip`·`resources-ui.zip`·`resources-audio.zip`·`resources-portraits.zip`으로 분리됩니다. 기본 ZIP 옆의 `resource-packs.json`을 포함한 전체 빌드 묶음을 사용합니다. 클라이언트 GameTest는 4개 ZIP을 각각 선택하며 서버가 내보낸 지도 블록 상태와 생성 팔레트도 함께 불러옵니다. 모델은 공군기지 63·해군기지 70·레이더 49·도시 100큐브, 승점은 앞뒤 면을 가진 평면입니다. 실제 운영 서버의 다운로드와 다중 접속 동기화는 이 렌더링 fixture 검증에 포함하지 않습니다.


국가 정보 국기 버튼은 원본 국기 비율에 맞춰 가로로 넓히고 TFR의 `gfx/interface/flag_overlay.dds` 원본 오버레이(98×67)를 덧씌웁니다. 82×52 국기는 프레임 안쪽에 배치하며, 광택·음영은 원본 이미지의 알파 합성을 사용합니다. 해당 버튼과 세계 긴장도 아이콘·백분율의 마우스 툴팁은 표시하지 않습니다. 다른 국가 수치 설명과 키보드 접근용 버튼 이름은 유지합니다. 금융 수치 칸 폭을 조정해 일반 화면의 지표가 모두 들어가도록 했습니다.

건설 프로빈스 시설은 보급 중심지·철도, 해군기지·요새, 해안 요새 순서입니다. 철도 버튼은 서버가 제공한 선택 항목으로 두 프로빈스를 차례로 지정하며, 서버가 신규 건설·증설·취소를 처리합니다. 해군·공군 강은 각각 기본 바다와 같은 회색·밝은 회색 콘크리트 재질입니다. 새 재질의 `atlas_scene_v3`/`atlas_scene_ready_v3`는 서버와 함께 갱신해야 합니다.

분할 팩의 실제 렌더링 검사는 네 ZIP을 모두 적용하여 원본 UI·소리와 철도 아이콘, 버튼 순서, 국기 비율, 전체 강 재질의 64블록 거리 처리를 검사합니다. 운영 서버의 팩 HTTP 다운로드·다중 접속은 서버를 실행하지 않았으므로 별도 확인이 필요합니다.

프로빈스 경계는 육상·해상 모두 회색, 주·해역·공역·해안 경계는 검은색입니다. `atlas_scene_v3`/`atlas_scene_ready_v3`를 서버와 함께 사용합니다. 육상 높이는 서버 NBT에 저장되며 실행 중 지형 종류로 추가하지 않습니다. 오키나와의 겹친 연결은 두 표시 프로빈스 사이 직선 하나로 표시합니다. `AtlasSurfaceRenderChecks`는 오키나와·프놈펜·중국 내륙의 서버 출력 fixture를 실제 렌더러로 확인합니다. 운영 서버 재접속·다중 접속 검증은 별도입니다.

무역 목록은 국가·수출·운송됨·수송선을 표시하고 행을 눌러 별도 계약 창을 엽니다. 경로 불가 및 양방향 금수는 빨강, 거래 가능한 미거래 국가는 노랑, 현재 계약이 있는 국가는 초록입니다. 민간공장 아이콘과 노란색 이용 가능 수치를 표시합니다. 수송선 필요 수는 서버 경로 계산값이며 육로는 0, 알 수 없거나 경로가 없으면 —입니다. 생산 라인은 맨 위로 이동 외에 한 줄씩 위·아래 이동하며 공장 효율을 그대로 보존합니다.

장교단은 육군·해군·공군·특수부대 구역을 원본 배너와 배경으로 구분합니다. 정보기관은 창설 전 창설 버튼만, 창설 후 개선 버튼과 작전/암호학 탭을 표시하고 개선은 별도 분류 창으로 엽니다. 화면에 없는 원본의 장교·개선 효과를 임의로 추가하지 않으며 현재 서버에 등록된 정보만 표시합니다. GUI 3 (2560×1440) 렌더러 캡처를 추가했습니다. 글꼴은 Minecraft의 현재 기본 폰트 렌더러이며 HOI 전용 한글 폰트를 따로 덮어쓰지 않습니다. 사용자가 적용한 다른 리소스팩의 기본 폰트는 영향을 줄 수 있습니다.
